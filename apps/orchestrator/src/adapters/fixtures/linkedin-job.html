JOB DESCRIPTION

The Front-End Developer will be responsible for designing and implementing user

interfaces for web and mobile applications, ensuring usability, responsiveness, and visual

consistency. This role combines front-end development expertise with basic UI/UX design

skills to deliver intuitive and engaging user experiences in the absence of a dedicated UX/UI

designer.

Key Responsibilities

• Design and implement user interfaces for web and mobile platforms using modern frameworks (ReactJS, React Native).

• Develop and maintain user-facing features ensuring responsive design and accessibility standards.

• Create wireframes and mockups to visualize layouts and user flows.

• Collaborate with product owners and stakeholders to translate requirements into functional and visually appealing interfaces.

• Integrate APIs and work closely with back-end developers for seamless data exchange.

• Optimize application performance and ensure cross-browser compatibility.

• Maintain code quality through testing, debugging, and adherence to best practices.

• Stay updated on emerging front-end technologies and design trends

• Exposure to UI/UX design principles and tools (Figma, Adobe XD).

Technical Skills:

o Proficiency in HTML5, CSS3, JavaScript (ES6+).

o Experience with ReactJS and React Native.

o Familiarity with RESTful APIs and JSON.

o Knowledge of responsive design and accessibility standards.

o Version control (Git) and CI/CD pipelines.

• Soft Skills:

o Strong problem-solving and analytical skills.

o Ability to work independently and in Agile teams.

o Good communication and stakeholder management skills.

Preferred Skills

• Experience with AWS or other cloud platforms.

• Knowledge of SEO best practices and performance optimization.

• Familiarity with UI frameworks (Material UI, Bootstrap).

Key Performance Indicators (KPIs)

• Timely delivery of front-end components aligned with project milestones.

• Quality and usability of UI designs without dedicated UX support

• Application performance and responsiveness across devices.

• Positive stakeholder feedback on user experience

REQUIREMENT

● Bachelor's degree in Information Technology, Computer Science, Engineering, or a related discipline.

● Minimum 5 years of experience in Frontend Developer (ReactJS, React Native)

● Ability to work collaboratively in a team

● Experience working in Agile environments

● English proficiency required for communication.
